# CloudNote Web

CloudNote 是一个基于 React + Vite 构建的云笔记 Web 应用，覆盖笔记创建、编辑、搜索、分享、历史版本、回收站和可观测性接入等完整流程，支持中文 / 英文双语界面。

## 项目特性

| 模块 | 能力说明 |
| --- | --- |
| 登录与鉴权 | 对接统一认证登录，支持回调参数解析、登录态恢复、未登录跳转登录页。 |
| 笔记工作台 | 提供左侧导航、中间笔记编辑区、右侧 AI 面板的三栏式工作台布局。 |
| 笔记列表 | 支持最近笔记、星标笔记、笔记本、回收站、分享页、我的分享等入口。 |
| 多类型编辑器 | 支持纯文本、提纲、思维导图、手写、语音笔记等编辑模式。 |
| 搜索能力 | 支持顶部快速搜索、搜索面板、全文搜索结果页和高亮展示。 |
| 分享能力 | 支持公开分享、指定用户分享、分享链接、有效期、分享范围配置。 |
| 历史版本 | 支持历史版本查看与版本恢复，个人笔记不展示多余用户信息。 |
| 回收站 | 支持删除笔记的查看、恢复和二次处理。 |
| 国际化 | 支持 `zh-CN` 与 `en-US` 双语切换，界面文案跟随语言变化。 |
| 可观测性 | 接入路由性能、编辑器初始化、搜索 / 分享 / 语音等关键事件，以及错误监控和华为云 APM SDK。 |
| 导入任务 | 支持从任务中心导入任务内容到笔记工作流。 |

## UI 交互流程

### 1. 登录与进入工作台

1. 用户访问应用后，系统先检查登录态。
2. 如果地址中携带统一认证回调参数，应用会自动完成登录回调处理。
3. 登录成功后默认进入 `近期笔记` 页面，路由为 `/cloudnote/recent`。
4. 如果未登录，会跳转到统一认证登录页，登录完成后再回到原页面。

### 2. 工作台整体布局

1. 页面采用三段式布局：
   - 左侧导航栏：工作区、笔记本、收藏、回收站等入口。
   - 中间主区域：笔记列表与编辑器。
   - 右侧面板：AI 助手，可按需打开或关闭。
2. 左侧和中间区域都支持收起、展开与宽度调整。
3. 顶部提供搜索、语言切换、导入任务、账号菜单等全局操作。

### 3. 笔记浏览与切换

1. 用户可以从最近笔记、星标笔记、笔记本、回收站、分享页等入口进入不同列表。
2. 列表项直接读取笔记自身状态，例如 `isShared`，用于展示分享态和相关标识。
3. 点击某条笔记后，编辑区加载对应内容。
4. 对于笔记本页，支持在笔记本与笔记之间联动浏览。

### 4. 笔记编辑流程

1. 打开笔记后，编辑区根据笔记类型选择对应编辑器。
2. 当前支持的类型包括：
   - `text`：富文本 / 普通文本
   - `outline`：提纲笔记
   - `mind`：思维导图
   - `handwritten`：手写笔记
   - `voice`：语音笔记
3. 编辑过程中，系统会同步标题、正文、状态等基础信息。
4. 语音笔记支持录音、转写与结果落盘。
5. 编辑器初始化、切换和关键操作会被记录到观测系统中。

### 5. 分享流程

#### 5.1 打开分享弹窗

1. 点击编辑区顶部的分享图标。
2. 弹窗先读取当前笔记的分享状态 `isShared`。
3. 如果当前笔记已开启分享，弹窗直接展示分享链接与配置。
4. 如果当前笔记未开启分享，只显示开关与基础说明。

#### 5.2 开启公开分享

1. 将分享开关切到开启。
2. 前端按当前 `noteId` 生成分享链接，格式为 `/cloudnote/shares/:noteId`。
3. 用户可以设置分享有效期。
4. 确认后调用创建分享接口：
   - `POST /v1/note/shares`
5. 创建成功后，列表、详情、弹窗内状态会同步回写为已分享。

#### 5.3 指定用户分享

1. 将分享范围切换为 `指定用户可访问`。
2. 系统打开用户查询弹窗。
3. 用户在搜索框输入工号、用户名或昵称，按回车触发查询。
4. 查询接口：
   - `GET /v1/note/user?searchText=...`
5. 搜索结果左侧展示可选用户，右侧展示已选用户。
6. 选择完成后点击 `确认`，回到分享弹窗。
7. 分享弹窗中显示已选用户的昵称。
8. 确认保存时调用创建分享接口，提交用户列表和有效期。

#### 5.4 关闭分享

1. 将分享开关关闭。
2. 关闭后当前分享链接失效。
3. 列表页、详情页和弹窗状态同步回写为未分享。

### 6. 用户查询与选择弹窗

1. 用户查询弹窗采用左右布局：
   - 左侧：搜索框 + 查询结果列表。
   - 右侧：已选用户列表 + 操作按钮。
2. 搜索结果以单行卡片展示，保留昵称、工号 / 用户名、部门等关键信息。
3. 已选用户列表只保留必要字段，避免内容冗余。
4. 左右列表支持滚动，但不额外展示滚动条，避免拉高弹窗。
5. 右下角提供 `取消` 和 `确认`，确认后回填到分享弹窗。

### 7. 历史版本流程

1. 在编辑区右上角更多菜单中选择 `历史版本`。
2. 右侧弹出历史版本面板。
3. 每条版本记录展示版本信息和当前版本标识。
4. 个人笔记历史版本不显示用户信息，保持界面简洁。
5. 点击恢复按钮可回滚到指定版本。

### 8. 搜索流程

1. 在顶部搜索框输入关键词。
2. 回车后打开搜索面板或进入搜索结果页。
3. 搜索面板支持快速定位，结果页支持完整浏览。
4. 搜索结果会保留笔记类型、分享态和高亮展示。

### 9. 语言切换与个人菜单

1. 右上角头像菜单提供语言切换、导入任务和退出登录。
2. 语言在 `zh-CN` 与 `en-US` 之间切换后，页面文案实时更新。
3. 分享弹窗、用户查询弹窗、错误提示等都支持双语适配。

### 10. 可观测性与 APM

1. 应用启动时会初始化观测系统。
2. 已接入的埋点和监控包括：
   - 路由性能统计
   - 编辑器初始化统计
   - 搜索 / 分享 / 语音等关键业务事件
   - ErrorBoundary 与全局异常捕获
3. 第三阶段已完成华为云 APM SDK 接入，支持通过环境变量配置启用。

## 开发与运行

```bash
cd note-web
npm install
npm run dev
```

常用命令：

```bash
npm run build
npm test
npm run preview
```

Electron 调试与打包：

```bash
npm run electron:dev
npm run electron:build
```

## APM 配置

如果需要启用华为云 APM，可通过环境变量覆盖配置：

```bash
VITE_APM_ENABLED=true
VITE_APM_APP_ID=your-app-id
VITE_APM_DOMAIN=your-domain
VITE_APM_SERVICE_NAME=note-web
VITE_APM_SCRIPT_URL=https://...
VITE_APM_SAMPLE_RATE=1
```

## 目录说明

```text
note-web/
├─ src/
│  ├─ components/        # 业务组件、编辑器、分享、历史、搜索等
│  ├─ pages/             # 页面级路由
│  ├─ services/          # 接口请求层
│  ├─ store/             # Zustand 状态管理
│  ├─ utils/             # 通用工具、观测、排序、国际化等
│  └─ locales/           # 中英文文案
├─ public/               # 静态资源
├─ config.json           # 运行 / 观测相关配置
└─ vite.config.js        # Vite 构建配置
```
